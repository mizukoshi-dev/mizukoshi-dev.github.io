プライバシーポリシー

対象: rclone-backup（最終更新 2026-10-12）

  • 本ツールは所有者本人だけが使う個人用のバックアップツールです。
  • Google ドライブへのアクセスは、本ツールが作成したファイルに限られます（スコープ drive.file）。
  • 保存するデータは所有者本人の PC 上で暗号化され、所有者本人の Google ドライブにだけ保存されます。
  • データや認証情報を、開発者を含む第三者へ送信・共有・販売することはありません。
  • Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。
  • アクセスはいつでも Google アカウントの設定から取り消せます。

Privacy Policy (English)

rclone-backup is a personal backup tool used only by its owner. It accesses only files it creates in the owner's Google Drive (drive.file scope). Data is encrypted on the owner's PC and stored only in the owner's Google Drive. No data or credentials are sent to, shared with, or sold to any third party. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from Google Account settings.
